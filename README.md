# Strategic Market and Trend Analysis

## Project Overview

This project focuses on analysing an apparel sales dataset to identify important sales patterns and trends across regions, stores, products, and time periods.

The project also explores different forecasting approaches to estimate future sales and evaluate their performance.

## Objectives

- Analyse overall sales performance
- Compare sales across regions and stores
- Identify top-performing products
- Analyse yearly and monthly sales trends
- Apply forecasting techniques
- Evaluate forecasting models using MAE, RMSE and R²
- Provide strategic business recommendations

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab

## Analysis Performed

### Regional Sales Analysis
The West region recorded the highest total sales.

### Store Sales Analysis
Store2 recorded the highest total sales.

### Product Sales Analysis
Product 128 was the highest-performing product based on total sales.

### Time-Based Analysis
Sales showed substantial growth toward the later part of the dataset, with April 2024 recording the highest monthly sales.

### Forecasting
The project explored:
- Linear Regression
- Holt-Winters Exponential Smoothing
- Log Linear Regression
- Three-Month Moving Average

The three-month moving average produced a next-month baseline forecast of **53,391,637**.

## Model Evaluation

The forecasting models were evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

The analysis demonstrates how sales data can be used to understand business performance, identify trends, support inventory planning, and make data-driven decisions.
